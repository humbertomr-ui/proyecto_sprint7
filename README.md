# Used Car Market Dashboard
Aplicación web interactiva desarrollada con Streamlit para explorar datos de anuncios de vehículos usados.

## Objetivo

Crear una aplicación web que permita visualizar información del mercado de autos usados mediante gráficos interactivos.

## Tecnologías y Herramientas

- Python
- Pandas
- Plotly Express
- Streamlit
- Render
- GitHub

## Habilidades demostradas

- Análisis Exploratorio de Datos (EDA)
- Manipulación y limpieza de datos con Pandas
- Visualización interactiva con Plotly Express
- Desarrollo de aplicaciones web con Streamlit
- Despliegue de aplicaciones en Render
- Control de versiones con Git y GitHub

## Funcionalidades

- Visualización de un histograma.
- Visualización de un gráfico de dispersión.
- Interacción mediante botones o casillas de verificación.
- Aplicación desplegada en Render.

## Dataset

El proyecto utiliza el archivo `vehicles_us.csv`, que contiene información sobre anuncios de vehículos usados.

## Conclusión

Este proyecto integra todo el flujo de desarrollo de una aplicación de análisis de datos, desde el análisis exploratorio del conjunto de datos hasta la creación, documentación y despliegue de una aplicación web interactiva utilizando Python, Pandas, Plotly Express, Streamlit, GitHub y Render.
